# 🎧 Audio Device Router

Расширение для Chrome/Edge: позволяет направлять аудио любой вкладки
на выбранное устройство вывода (наушники, колонки, виртуальный кабель).

## Возможности

- 🎯 Выбор устройства вывода для конкретной вкладки
- 🌐 Глобальное устройство для всех вкладок
- 🔇 Мгновенное переключение и остановка захвата

## Установка

1. Скачай или клонируй репозиторий.
2. Открой `chrome://extensions` (или `edge://extensions`).
3. Включи **Режим разработчика** (справа вверху).
4. Нажми **Загрузить распакованное расширение** и выбери папку проекта.
5. При первом запуске дай разрешение на микрофон (нужно для доступа к списку устройств).

## Использование

1. Открой вкладку с аудио (YouTube, Twitch и т.д.).
2. Кликни на иконку расширения.
3. Выбери наушники в списке → **Применить**.
4. Для отката — **Стоп**.
